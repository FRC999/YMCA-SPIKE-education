# Class preparation and printing

For Sessions 4 and 5, print one [Week 4 class packet](../../02_Student/Printouts/W04_Class_Print_Packet.pdf) or [Week 5 class packet](../../02_Student/Printouts/W05_Class_Print_Packet.pdf) for the corresponding class. Use US Letter, Actual Size, single-sided and automatic page orientation. Each starts with the mentor checklist and contains two field sets and one team sheet for each of four teams plus a spare.

For Session 6, print one [22-page rescue packet](../../02_Student/Printouts/W06_Class_Print_Packet.pdf) with the same settings. It contains two rescue fields with movable tabs, five team sheets, four build cards and attendance.

For Session 2, use the [complete teaching-file and packing checklist](W02_delivery_Checklist.md). Print one [14-page class packet](../../02_Student/Printouts/W02_Class_Print_Packet.pdf), single-sided, plus the optional [two-page checklist](W02_delivery_Checklist.pdf). Reuse role cards and hub guides.

For the Week 7 timed delivery option, print one [44-page class packet](../../02_Student/Printouts/W07_speed_trial_Class_Print_Packet.pdf). It has the [mentor checklist](W07_speed_trial_Checklist.md), two full-size courses, five team sheets, four build cards and attendance. Calibrate both kits on the actual floor before class.

For the first session on October 27, use the [complete readiness guide](W01_Readiness_Guide.md) ([four-page PDF](W01_Readiness_Guide.pdf)): batteries, charging, software setup, exact print list, packing and arrival checks. The [16-page class packet](../../02_Student/Printouts/W01_Class_Print_Packet.pdf) already includes the required quantities; print ONE copy, single-sided.

Use the matching week below. Each checklist covers 12 children in four teams of three, two SPIKE kits and 4–6 student instructors plus an adult lead. Pack the [reusable kit](Reusable_Kit.md) every week. Quantities are targets; check owned supplies before buying.

Print worksheets single-sided at actual size on US Letter. PDF files open on GitHub for reading; download or use the PDF viewer’s print command for reliable printing. The class deck is for display, not a student handout. Speaker notes are available digitally; one printed lead copy is optional.
