# Research sources

Checked October 1, 2026. Original curriculum recommendations are distinguished from source facts.

## 1. [LEGO SPIKE portfolio update](https://education.lego.com/en-us/spike-update-2026/)

SPIKE sales ended June 30, 2026. App and curriculum support continues through June 30, 2031. Existing kits are suitable for this pilot.

## 2. [LEGO SPIKE App download](https://education.lego.com/en-us/downloads/spike-app/software/)

Official software entry point. Check the requirements for the exact proposed devices and test Python, connection, and project saving before enrollment.

## 3. [LEGO Training Camp 1 Driving Around](https://education.lego.com/en-us/lessons/prime-competition-ready/training-camp-1-driving-around/)

Free beginner driving lesson for grades 6 to 8, with a base build and movement exercises. Use its build as the common chassis, with our port assignments.

## 4. [LEGO Practice Driving Base instructions](https://assets.education.lego.com/v3/assets/blt293eea581807678a/blt06873e1b438a0d7e/5ec8e66f033ad5045f4c79a6/driving-base-bi-pdf-book1of1.pdf?locale=en-us)

Official illustrated assembly sequence. Follow the complete build before the pilot, then cable the left motor to A and right motor to B for our code.

## 5. [LEGO Python Communicating Ideas unit](https://education.lego.com/en-us/lessons/prime-python-communicating-ideas/)

Free Python sequence for grades 6 to 8 with hardware, light, and collaboration lessons. Useful mentor preparation and optional follow-on learning.

## 6. [LEGO Python teacher guide Units 1 to 5](https://assets.education.lego.com/v3/assets/blt293eea581807678a/blt834b554cdaa246f7/6584064fd082f7672425e7ea/File_1_Units12345_Intro_to_Python_Course_TG_Course.pdf?locale=en-us)

A much longer official Python curriculum. Select background lessons rather than attempt to compress the entire course into eight hours.

## 7. [LEGO Cart Control](https://education.lego.com/en-au/lessons/spike-python-u3-sensor-control/spike-python-u3l3/)

Official sensor example verifies distance readings in millimeters and the invalid-reading check. Our original missions use short bounded movements.

## 8. [LEGO live Python help](https://spike.legoeducation.com/prime/modal/help/lls-help-python)

Final authority for the installed SPIKE App Python API. Open Help in a Python project if the direct link does not display.

## 9. [Tufts CEEO SPIKE 3 documentation archive](https://tuftsceeo.github.io/SPIKEPythonDocs/SPIKE3.html)

University-hosted documentation used to cross-check signatures. It is an archive, so check installed app help if an API differs.

## 10. [Dodd Program of Studies Career and Technical Education](https://sites.google.com/cheshire.k12.ct.us/doddmsprogramofstudies/unified-arts/career-technical-education)

Describes robotics and programming learning. The public description does not establish which robot kit is currently used. Ask the school before claiming alignment or novelty.

## 11. [FIRST Team Attribute Awards](https://www.firstinspires.org/resources/library/frc/team-awards)

Engineering Inspiration emphasizes measurable STEM recruitment and community education with ongoing effort. It is normally evaluated through team interactions rather than a separate Impact-style essay.

## 12. [FIRST Submitted Awards](https://www.firstinspires.org/resources/library/frc/submitted-awards)

Impact recognizes sustained work, with particular attention to the last three years. The page lists a February 11, 2027, 3 p.m. ET Impact deadline as checked October 1, 2026. Recheck current season instructions.

## 13. [FIRST judging best practices](https://community.firstinspires.org/hubfs/web/program/frc/awards/best-practices-for-teams.pdf)

Connect outreach to its purpose, preserve measurable evidence, and prepare students to explain their contributions.

The unmodified driving-base PDF is included for convenient class preparation. Image credit for the driving-base illustration in the week 1 slides: LEGO Education, Training Camp 1. No endorsement is implied.
