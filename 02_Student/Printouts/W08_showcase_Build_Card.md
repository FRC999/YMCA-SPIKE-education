# Week 8 build card

## A working exhibit for the showcase

Team ____  Builders A ____ B ____ C ____

Finish a stable exhibit that helps visitors understand the team’s robot job.

**Materials:** The saved team build and program, a small card sign, pre-cut card, tape and spare repair parts.

## Try it

1. Repair or strengthen one loose part of the saved build.
2. Add a small sign or model showing the user and useful job.
3. Rehearse three short speaking parts while the robot is with the other team.

## Our jobs

Builder connects pieces. Designer chooses/finds parts and checks the plan. Tester performs the hand test and reports one result. Everyone builds. Rotate when the mentor calls time.

## Test and improve

Exhibit stands, robot lane stays clear, and each child can explain one part.

We noticed ____________________. We changed ____________________.

This is finishing and presentation time, not a new complex mechanism. Each team gets a six-minute robot rehearsal and a four-minute demonstration.

Fit attachments only to a stopped robot after the mentor checks clearance. Leave wheels, buttons, cables and sensors clear.
