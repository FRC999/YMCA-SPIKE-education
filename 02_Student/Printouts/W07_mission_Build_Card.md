# Week 7 build card

## A small community mission scene

Team ____  Builders A ____ B ____ C ____

Build a small scene or improve an attachment for a chosen community job.

**Materials:** Earlier team attachments, spare parts, pre-cut card, tape, a lightweight cube, and parking or marker course pieces.

## Try it

1. Choose a user and one job: deliver to a floor marker or stop near a garage wall.
2. Build the matching destination, useful attachment or model of the user’s need.
3. Hand-test the scene, identify one weak feature and improve it.

## Our jobs

Builder connects pieces. Designer chooses/finds parts and checks the plan. Tester performs the hand test and reports one result. Everyone builds. Rotate when the mentor calls time.

## Test and improve

One useful job, a clear route and a visible success condition; no new untested electronics.
